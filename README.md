## How to Get Started

### Clone the repository

```bash
git clone https://github.com/pranshulrajyan/Learning-AI-ML.git
cd Learning-AI-ML
```

### Set up the environment

Install Python and Jupyter Notebook, then install the libraries needed for the notebooks:

```bash
python -m pip install numpy pandas matplotlib scikit-learn jupyter
```

### Run the notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Alternatively, open the repository in VS Code and run the `.ipynb` notebooks using a configured Python environment.
